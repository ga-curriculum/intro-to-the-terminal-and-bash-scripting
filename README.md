## About

In this module, students learn to use the terminal as a new way to communicate with their computer. They’ll start by exploring simple commands to navigate and manage files without relying on visual interfaces. By the end, students will understand how to create and run basic scripts, laying the groundwork for automating tasks and creating new types of workflows.
